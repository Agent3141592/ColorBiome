# ColorBiome

ColorBiome lets players customize vegetation and water colors in selected Minecraft areas without changing the actual biome.

Use the Palette Brush to select an area, choose separate biome palettes for vegetation and water, and set the vertical range where the colors should apply. The mod supports both vanilla and modded biomes.

## Development

- Minecraft 1.21.1
- NeoForge 21.1.227 or newer
- Java 21

Build the mod with:

```powershell
.\gradlew.bat build
```

The built jar is created in `build/libs`.
